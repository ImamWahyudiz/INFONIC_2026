Materi & Modul Pembekalan

VS Code
Editor kode standar industri. Panduan instalasi, konfigurasi awal, *shortcut*, dan rekomendasi ekstensi produktif.
Git & GitHub
Fondasi version control developer modern: git init, commit, branching, hingga push ke remote repository.
Figma UI/UX
Prinsip antarmuka pengguna, wireframing, layout komponen modern, hingga merancang prototype aplikasi interaktif.
Flowchart & Logika
Pemodelan algoritma dan alur logika terstruktur sebelum memulai penulisan baris kode pemrograman.
Troubleshooting & Path
Solusi praktis mengatasi error Git not recognized, navigasi terminal folder berspasi, dan tips keluar dari editor terminal.
Kolaborasi & Fork PR
Praktik langsung alur kerja tim di GitHub: cara Fork repositori, membuat branch baru, mengirim Pull Request, hingga submit tugas osjur.
