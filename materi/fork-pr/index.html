1. Alur Sistem Pengumpulan Tugas

Pengumpulan tugas di INFONIC 2026 menggunakan sistem bertingkat (hierarki). Mahasiswa Baru (Maba) melakukan fork dan mengirimkan Pull Request ke repository Kakak Pembimbing (Kabim) masing-masing gugus, bukan langsung ke repository pusat.

1. Mahasiswa Baru (Peserta)

Fork repo Kabim gugus → Tambah file tugas di Tugas/<Gugus>/NIM_Nama.md → PR ke repo Kabim.

Tahap 1
Maba Pull Request ke Repository Kabim Gugus

2. Kakak Pembimbing (Kabim)

Kabim mereview tugas maba, memastikan link publik, lalu merge PR maba ke repo gugus.

Tahap 2 (Review)
Kabim Fork & Pull Request ke Repository Utama

3. Repository Pusat INFONIC 2026 (Panitia / Ketua)

Panitia pusat mereview akumulasi pengumpulan seluruh 12 gugus dan memfinalisasi nilai.

Tahap 3 (Final Merge)
Penting: Tanyakan link repository GitHub Kabim kepada Kakak Pembimbing gugusmu masing-masing saat sesi FGD/grup koordinasi gugus.

3. 5 Langkah Pengumpulan Tugas

  1. 1
    Fork Repository Kabim Gugusmu

    Buka tautan repository GitHub milik Kabim gugusmu di browser.

    Klik tombol Fork di pojok kanan atas. Pilih akun GitHub pribadimu. Sekarang kamu memiliki salinan repository tugas di akun GitHub pribadimu.

  2. 2
    Clone ke Laptop & Buka di VS Code

    Salin link HTTPS dari repository hasil fork pribadimu. Buka terminal / Git Bash di laptop:

    git clone https://github.com/USERNAME-KAMU/INFONIC_2026.git

    Buka folder tersebut di VS Code (File → Open Folder...).

  3. 3
    Buat File Tugas Baru di Folder Gugusmu
    Dilarang Mengedit File Template: Jangan mengedit file Tugas/NIM-NAMA.md! Buat file baru atau copy template tersebut menjadi file tersendiri.
    Tak sengaja terubah? Lihat Panduan Membatalkan File Salah Edit di Troubleshooting →

    Buka folder gugusmu di dalam Tugas/<NamaGugus>/ (contoh: Tugas/JavaScript/).

    Buat file baru bernama: NIM_NamaLengkap.md (contoh: 26106050001_MuhammadAdzka.md).

    Salin format dari template Tugas/NIM-NAMA.md, lalu isi data diri dan seluruh tautan tugas (Week 1 – Week 4). Simpan dengan Ctrl + S.

  4. 4
    Commit & Push ke Repository GitHub Pribadimu

    Buka terminal VS Code (Ctrl+`) dan jalankan perintah berikut:

    git add .
git commit -m "Submit tugas osjur - <NIM_KAMU>"
git push origin main

    Contoh: git commit -m "Submit tugas osjur - 26106050001"

  5. 5
    Buat Pull Request ke Repository Kabim

    Buka browser dan buka repository hasil fork di akun GitHub-mu.

    1. Klik tombol Contribute → Open Pull Request.
    2. Pastikan base repository mengarah ke repository Kabim gugusmu.
    3. Judul PR: Submit tugas osjur - <NIM_KAMU>
    4. Deskripsi PR: Sebutkan Gugus dan Nama Lengkapmu.
    5. Klik Create pull request.
    Selesai! Kabim gugusmu akan memeriksa tugasmu dan melakukan merge PR.

4. Aturan & Larangan Mutlak

Pull Request kamu akan LANGSUNG DITOLAK jika:
  • Mengedit file template asli Tugas/NIM-NAMA.md atau file milik teman lain.
  • Menaruh file di luar subfolder gugus yang telah ditentukan.
  • Format penamaan file salah (menggunakan spasi, dash, atau tanpa ekstensi .md).
  • Link tugas (Google Drive, Figma, dsb.) bersifat private / terkunci.
  • Mengubah file root seperti index.html, README.md, atau konfigurasi sistem.

Standar Format Penamaan File

Tugas/<NamaGugus>/<NIM>_<NamaLengkap>.md

# Contoh BENAR:
Tugas/JavaScript/26106050001_MuhammadAdzka.md
Tugas/Python/26106050012_SitiFatimah.md

# Contoh SALAH:
Tugas/NIM-NAMA.md                     (Mengedit template)
Tugas/Python/26106050012 Siti.md      (Ada spasi)
Tugas/26106050012_SitiFatimah.md      (Di luar folder gugus)

Pengaturan Hak Akses Link Tugas

Semua link yang kamu cantumkan di dalam file markdown wajib disetel ke "Anyone with the link can view" (Siapa saja yang memiliki link dapat melihat). Panitia & Kabim tidak dapat memberi nilai jika file terkunci (*access denied*).

5. Checklist Sebelum Buat PR

  • File dinamai dengan format NIM_NamaLengkap.md (menggunakan underscore _).
  • File berada di dalam folder gugusmu sendiri (contoh: Tugas/JavaScript/).
  • File template Tugas/NIM-NAMA.md tidak tersentuh/diedit sama sekali.
  • Seluruh link tugas (Drive/Figma/GitHub) bisa dibuka di mode *Incognito/Private window* tanpa perlu login.
  • Sudah menjalankan git push origin main ke repository GitHub pribadimu.
  • Tujuan Pull Request diarahkan ke repository Kabim gugusmu.
  • Judul PR diisi sesuai format: Submit tugas osjur - <NIM>.
